# config

환경 설정의 순수 입력 검증을 담당한다.

## 주요 파일

| 파일               | 역할                                                                             |
| ------------------ | -------------------------------------------------------------------------------- |
| `settings.test.ts` | `BACKEND_URL` 필수·절대 HTTP(S) URL·끝 슬래시와 쿠키 Secure 설정의 우선순위 검증 |

## 작업 규칙과 검증

`loadSettings()`에 환경 객체를 직접 넘긴다. 예시 환경 파일과 다른 프로브 주소를
사용해 입력을 무시하고 기본값을 반환하는 결함을 구별한다. 누락·공백·상대 URL·
지원하지 않는 스킴과 잘못된 불리언 입력을 별도 사례로 유지한다.

루트에서 `pnpm exec vitest run test/unit/config`를 실행한다. 내부 의존성은
`lib/config/settings.ts`, 외부 의존성은 Vitest다. 전체 게이트는 `./scripts/check.sh`다.
